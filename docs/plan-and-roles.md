# План и роли

Обновлено после встречи с Д. В. Парфеновым 19.10.2026. Окончательный список методов будет после его письма со статьями.

## Что требуется

- Задачи: быстрая генерация сочетаний и быстрая генерация перестановок — с повторениями и без. Коды Грея — позже, если хорошо справимся с первыми двумя.
- Только новые алгоритмы из статей последних лет (подборку пришлёт Парфенов). Реализация известного старого метода не засчитывается.
- Один метод на человека. Можно в парах: один пишет теорию на два метода, другой их программирует.
- Отчёты — только в LaTeX.
- Код: каждый метод — класс. Конструктор задаёт первое сочетание или перестановку, каждый вызов `operator()` без параметров выдаёт следующее, всё состояние хранится внутри объекта. Программу проверки (все объекты, без пропусков и повторов) Парфенов даст в конце.

## Ближайшие шаги

1. Получить подборку статей от Парфенова и распределить методы.
2. Завести аккаунты на overleaf.com; общий шаблон отчёта в LaTeX — Алёна.
3. Принять приглашение в репозиторий.
4. Фон для всех: что такое loopless (каждый следующий объект за постоянное время в худшем случае) и CAT (в среднем); классика для сравнения — следующая перестановка в лексикографическом порядке, алгоритм Джонсона–Троттера, «вращающаяся дверь» для сочетаний.

## Задача считается готовой, если

- метод реализован классом с `operator()` и на маленьких n выдаёт все объекты без пропусков и повторов;
- теория и описание метода оформлены в LaTeX;
- автор может объяснить каждую строку.
