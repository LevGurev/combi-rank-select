# combi-rank-select — тема №60

Командный проект (РТУ МИРЭА, преподаватель Д. В. Парфенов):
**«Новые алгоритмы компьютерной комбинаторики: сочетания, перестановки, их rank/select и эффективная программная реализация (ДМ, АП, БД)»**.

- **rank** — по объекту получить его номер в упорядоченном списке всех объектов;
- **select** (он же unrank) — по номеру получить объект.

Пример: перестановки `0 1 2` по порядку — `012, 021, 102, 120, 201, 210`. Тогда rank(`120`) = 3, select(4) = `201`.

## Что уже есть (базовая версия)

| Объект | Порядок | Алгоритм | Операций* | Функции |
|---|---|---|---|---|
| Перестановки | лексикографический | по определению | O(n²) | `perm_rank_lex_naive`, `perm_unrank_lex_naive` |
| Перестановки | лексикографический | дерево Фенвика | O(n log n) | `perm_rank_lex`, `perm_unrank_lex` |
| Перестановки | Myrvold–Ruskey (2001) | обмены | O(n) | `perm_rank_mr`, `perm_unrank_mr` |
| Сочетания | lex и colex | комбинаторная система счисления | O(n) | `comb_rank_lex_u64`, `comb_unrank_colex_big` и др. |

\* В арифметических операциях. С длинными числами каждая операция стоит O(длины числа), и на больших n именно это определяет время — см. [docs/benchmarks.md](docs/benchmarks.md).

Тип номера: `std::uint64_t` (перестановки до n = 20, сочетания до n = 67) или `combi::BigUInt` — своя длинная арифметика без внешних библиотек, n любое.

Проверка: около 1,8 млн проверок, в том числе полный перебор всех перестановок до n = 8 и всех сочетаний до n = 16, сверка с независимой реализацией на Python (`tools/reference.py`), прогон под санитайзерами памяти.

## Как собрать и запустить

Нужны компилятор C++17 и CMake 3.14+.

**Windows, Visual Studio 2022** (с компонентом «Разработка классических приложений на C++»): *Файл → Открыть → Папка…* и выбрать папку проекта. Студия сама найдёт `CMakeLists.txt`. Вверху выберите конфигурацию `x64-Release`, цель `tests.exe`, `demo.exe` или `bench.exe` и нажмите ▶.

**CLion:** *Open* → папка проекта → выбрать цель → *Run*.

**Терминал (Linux, macOS, Windows с MinGW):**

```
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/tests          # тесты
./build/demo           # демонстрация
./build/bench          # замеры (до минуты); ./build/bench --quick — быстро
ctest --test-dir build # всё сразу
```

## Калькулятор

```
demo perm-rank 2 0 3 1     ->  lex rank: 13
demo perm-select 4 13      ->  lex: 2 0 3 1
demo comb-rank 5 0 2 4     ->  lex rank: 4, colex rank: 5
demo comb-select 5 3 4     ->  lex: {0 2 4}, colex: {0 1 4}
```

Номера могут быть любой длины.

## Статус

Базовая версия — разминка и инструменты: сборка, автопроверка, тесты перебором. Классические rank/select здесь нужны для проверки генераторов (все объекты, без пропусков и повторов), а не как результат проекта. Методы проекта — новые алгоритмы генерации сочетаний и перестановок из статей, которые даст Д. В. Парфенов; у каждого участника свой метод.
